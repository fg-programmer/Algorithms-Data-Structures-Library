# Algorithms and Data Structures

A collection of C++ implementations and assignments covering fundamental
programming concepts, data structures, and algorithms.

## Contents

### 0. Coding Language

Introduces the programming language.

### 1. Palindrome Checker and Sorting Algorithms

Implements a palindrome checker along with sorting-related algorithms
and supporting data structures.

**Topics include:** - Palindrome checking - Sorting algorithms -
Stacks - Queues - Linked-list nodes

**Key files:** - `Palindrome_Sorting.tex` - `Palindrome_Sorting.pdf` -
`Palindrome.h` - `SortingAlgorithms.h` - `Stack.h` - `Queue.h` -
`Node.h` - `main.cpp`

### 2. Hash Table and Search Algorithms

Explores hash tables and search algorithms through C++ implementations
and supporting test files.

**Topics include:** - Hash tables - Search algorithms - Algorithm
testing

**Key files:** - `Algorithms.h` - `main.cpp` - Assignment `.tex` and
`.pdf` files - Test/input files

### 3. Graph and BST Implementation

Implements graph and binary search tree data structures.

**Topics include:** - Graphs - Binary search trees (BSTs) - BST nodes -
Graph operations - BST searching and operations

**Key files:** - `Graph_and_BST.tex` - `Graph_and_BST.pdf` - `Graph.h` -
`BST.h` - `BSTNode.h` - `main.cpp`

### 4. Graph and Knapsack Implementation

Implements graph-related data structures and algorithms alongside an
implementation of the Knapsack problem.

**Topics include:** - Graph data structures - Graph algorithms - Edges
and graph connectivity - Knapsack problem - Algorithmic problem solving

**Key files:** - `Graph and Knapsack.tex` - `Graph and Knapsack.pdf` -
`Graph.h` - `Edge.h` - `Spice.h` - `main.cpp`

The `Spice.h` component is used as part of the Knapsack-related
implementation, while `Edge.h` and `Graph.h` provide the supporting
graph structure.

## Technologies

-   **C++** --- Algorithm and data structure implementations
-   **LaTeX** --- Assignment documentation and reports
-   **Text files** --- Test data and input/output files
